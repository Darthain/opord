# Reference / Licensing Notes

ARTIC AI v0.1 is written as original source code and does not redistribute models, textures or PBO contents from the reference mods.

The design has been informed by testing/review of:
- LAMBS Danger DEV
- Light AI Fire Support (LAFS)
- NR6 / HAL Evolved
- Gruppe Adler Trenches
- Pook Camonets
- IEDD
- DATE Battle Book Part 3: OPFOR Tactics, Techniques and Procedures
- ATP 3-21.8, Infantry Rifle Platoon and Squad (public U.S. Army doctrine; concepts only, no third-party code/assets)

Runtime adapters use public Arma configuration/class detection where possible. Optional mod assets remain in their original mods and are not included in ARTIC AI.

Before any future direct source reuse is distributed, verify and comply with the licence of the specific source being reused. The preferred ARTIC approach is clean reimplementation of the useful behaviour and optional runtime adapters.


## FPV Drone Crocus
ARTIC v0.3 includes a runtime adapter only. It recognizes Crocus public classnames/configured inventory and spawns the loaded Crocus UAV classes. No Crocus model, texture, binary or source file is included in ARTIC. Keep the Crocus mod and its own licence/distribution requirements separate.
