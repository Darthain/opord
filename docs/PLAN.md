# OPORD plan

Stub from Phase 1; the full plan is written in Phase 4.

## Planned addon layout
| Addon | Status | Content |
| --- | --- | --- |
| `main` | Phase 1 skeleton | Version, CBA settings, logging, shared helpers (function tag `OPORD`) |
| `soldier` | Phase 2 | Fork of DCO `soldierFSM` (PBO prefix `soldierFSM`), BSD-3-Clause |
| `soldier_module` | Phase 2 | Fork of DCO `fipo_module` (PBO prefix `fipo_module`), BSD-3-Clause |
| `defence` | Phase 3 | Battle positions, support by fire, statics, trenches |
| `test` | Phase 3 | Checkpoint test menu |
| `commander` | later | Eden/Zeus commander modules, ORBAT, objectives |
| `infantry` | later | Formations, section drills, platoon attack |
| `vehicles` | later | Core vehicle behaviour |
| `support` | later | Logistics, fires, CAS, drones |
| `intel` | later | Information network |
